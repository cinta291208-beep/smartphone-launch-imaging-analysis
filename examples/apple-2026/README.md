# Apple 2026 秋季发布会影像解读案例

这个案例展示 `smartphone-launch-imaging-analysis` Skill 如何处理一个同时包含 Pro 系列与折叠屏产品的发布会。

## 案例目标

- 将 iPhone 18 Pro、iPhone 18 Pro Max 与 iPhone Duo 放在同一场发布会叙事中分析，而不是割裂成多个独立页面。
- 从官方产品页与技术规格中完整提取影像卖点，并区分官方宣传、技术事实、博主观察和第三方解读。
- 在发布会首发上手之后，继续用更新的完整评测刷新结论。
- 将可变光圈、专业视频、音频处理、双屏取景等功能组织成可理解的影像系统，而不是简单罗列参数。
- 从光学、视频工作流、音频、折叠屏交互和竞争方向进一步分析行业启示。

## 页面设计要点

页面采用浅色编辑风格，封面以居中大标题和蓝白渐变为主，不依赖大幅产品图。核心功能通过侧导航 / Tab 切换，避免所有内容都堆成同尺寸卡片；主要卖点使用更大的视觉层级，次要能力压缩展示。创作者部分优先完整评测，并把“博主原始结论”“第三方技术解读”“跨来源综合判断”区分开。

## 这个案例验证了什么

1. 多机型发布会需要先解释产品角色，再比较参数。
2. 官方影像叙事不应只关注主摄和长焦，视频、音频和交互同样需要完整提取。
3. 发布会当天的上手内容不等于完整评测；当更新评测出现时，需要调整证据权重。
4. 第三方文章可以帮助解释技术现象，但不能被改写成博主本人说过的话。
5. “影像升级”既包括画质，也包括拍摄控制、专业工作流、声音和设备形态带来的新取景方式。
