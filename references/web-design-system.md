# Web Design System

## Visual direction

Default: light, premium, editorial, restrained. Use brand-inspired accents without copying the manufacturer's site.

Hero:
- centered title and introduction;
- subtle white-to-blue or brand-relevant gradient;
- no hero image unless it adds real information;
- strong typography and generous whitespace.

## Information density

Avoid repeated equal-size card grids. Use:
- large feature for the central selling point;
- medium cards for secondary evidence;
- compact rows/chips for tertiary facts;
- tabs or left-side navigation for feature families;
- expandable evidence when details are dense.

A useful desktop pattern:
- 200–240 px left feature navigation;
- content stage on the right;
- sticky navigation;
- horizontal tabs on mobile.

## Interaction

Use motion to explain hierarchy, not decorate everything:
- hover lift: 2–4 px;
- subtle shadow/border change;
- aperture animation for variable-aperture stories;
- fold animation for foldables;
- tab transition 250–400 ms;
- respect reduced-motion preferences when practical.

## Images and icons

Use official/product imagery only when it improves comprehension. Useful visuals:
- camera module crop;
- focal-length diagram;
- foldable dual-screen illustration;
- sample-photo pair with clear provenance;
- simple CSS/SVG-like icons for aperture, zoom, video, audio.

Do not add generic stock photos.

## Creator reviews

Prefer editorial rows or asymmetric review blocks over six identical cards. Show:
creator + date + review type + model + comprehensive summary + tags + original link.

Full reviews should visually outrank old hands-on content.

## Sources

Keep sources simple:
- heading above content;
- vertical numbering 1, 2, 3, 4…;
- source name and what it supports;
- no decorative dot-separated inline source cloud.

## Responsive

Test:
- hero title wrapping;
- sticky nav becoming horizontal tabs;
- 2-column synthesis becoming 1-column;
- long Chinese titles;
- source URLs/links;
- no horizontal overflow.
